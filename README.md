# EN Lesson Translator — локальный помощник на уроках английского

Десктопное приложение для Windows. Слушает системный звук (звонок/видео),
распознаёт английскую речь преподавателя, **дожидается, когда человек
закончит фразу** (по паузе в речи, а не по количеству слов), переводит на
русский, сохраняет историю локально. Работает **полностью офлайн** — все
модели (распознавание речи и перевод) выполняются на вашем компьютере, без
отправки данных куда-либо в интернет.

## Возможности

- Захват системного аудио (WASAPI loopback) — звук из звонка Zoom/Teams/Skype
  или видео в браузере, без виртуальных кабелей.
- VAD (детекция голосовой активности): перевод запускается только после
  того, как в речи возникла пауза ~0.7 сек — то есть после **окончания
  фразы**, а не после каждых 2-3 слов.
- Распознавание речи — `faster-whisper` (локальная модель Whisper).
- Перевод EN → RU — `argostranslate` (офлайн языковой пакет).
- Локальная история последних 50 фраз (SQLite), старые записи автоматически
  удаляются.
- Копирование перевода одним кликом (кнопка у текущей фразы и у каждой
  карточки истории).
- Контекст урока: лента предыдущих фраз + переводов + прикреплённых
  скриншотов.
- Снимок экрана по горячей клавише, автоматически прикрепляется к
  **следующей** распознанной фразе.

## Требования

- Windows 10/11, 64-бит.
- Python 3.10–3.12.
- Рекомендуется минимум 4 ГБ свободной RAM и современный CPU
  (модель Whisper "small" на CPU распознаёт фразу за 1–3 сек).

## Установка

```bash
cd english-lesson-translator
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### Разовая настройка моделей (нужен интернет один раз)

```bash
python scripts/setup_models.py
```

Это скачает:
- модель Whisper (`small` по умолчанию, см. `app/config.py` →
  `WHISPER_MODEL_SIZE`, можно сменить на `tiny`/`base`/`medium`);
- офлайн языковой пакет Argos Translate en→ru.

После этого шага интернет не требуется — всё распознавание и перевод
работают локально.

## Запуск

```bash
python main.py
```

Для глобальных горячих клавиш (библиотека `keyboard`) на Windows может
потребоваться запуск от имени администратора.

## Горячие клавиши (настраиваются в `app/config.py`)

| Клавиши          | Действие                                              |
|------------------|--------------------------------------------------------|
| `Ctrl+Shift+S`   | Сделать снимок экрана, прикрепить к следующей фразе     |
| `Ctrl+Shift+L`   | Старт/стоп прослушивания                                |

## Как работает определение "конец фразы"

1. Системный звук нарезается на кадры по 30 мс.
2. Каждый кадр проверяется детектором голосовой активности (`webrtcvad`).
3. Пока идёт речь — кадры копятся в буфере текущей фразы.
4. Короткие паузы (вдохи, < 700 мс по умолчанию) не прерывают фразу.
5. Как только тишина продержалась 700 мс подряд — фраза считается
   законченной и целиком отправляется на распознавание+перевод.
6. Короткие случайные шумы (< 400 мс речи) отбрасываются — это не фразы.
7. Если человек говорит очень долго без пауз (> 18 сек) — фраза форсированно
   разбивается, чтобы не копить гигантский буфер.

Параметры (`END_OF_SPEECH_SILENCE_MS`, `MIN_UTTERANCE_MS`,
`MAX_UTTERANCE_MS`) настраиваются в `app/config.py`.

## Структура проекта

```
english-lesson-translator/
├── main.py                     # точка входа
├── requirements.txt
├── scripts/
│   └── setup_models.py         # разовая загрузка офлайн-моделей
├── app/
│   ├── config.py                # все настройки в одном месте
│   ├── audio_capture.py         # захват системного звука (WASAPI loopback)
│   ├── vad_segmenter.py         # определение конца фразы по паузе
│   ├── speech_recognizer.py     # faster-whisper (локально)
│   ├── translator.py            # argostranslate EN->RU (локально)
│   ├── history_store.py         # SQLite, последние 50 фраз
│   ├── screenshot_manager.py    # снимки экрана + привязка к фразе
│   ├── hotkey_manager.py        # глобальные горячие клавиши
│   ├── pipeline.py              # связывает все модули вместе
│   └── ui/
│       └── main_window.py       # интерфейс (PySide6)
└── data/                        # создаётся автоматически: БД, скриншоты, модели
```

## Приватность

Все данные (аудио, распознанный текст, перевод, скриншоты, история) хранятся
только локально на вашем компьютере в папке `data/`. Ничего не отправляется
в облако.

## Возможные доработки

- Выбор конкретного loopback-устройства в UI (сейчас используется устройство
  вывода по умолчанию) — метод `SystemAudioCapture.list_loopback_devices()`
  уже готов для этого.
- Экспорт истории в текстовый файл/PDF.
- Настройка размера модели Whisper прямо из UI (сейчас — через
  `app/config.py`).
